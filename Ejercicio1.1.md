# CÓMO AGREGAR LAS GUEST ADDITIONS DE VIRTUALBOX EN WINDOWS 8.1 Y PONER EL BOTÓN DE INICIO DENTRO

Primero, si quieres instalar Windows 8.1 en VirtualBox, debes tener la ISO para instalarlo si las das al botón de *Nueva* para poner la ISO y modificar o cambiar las especificaciones de la máquina.

Y antes de dar al botón de *Terminar* pones la **Clave de Producto** para que funcione y se instale como si se lo pusieras en un ordenador normal.

Y cuando la máquina se haya terminado de configurar, debes seguir los siguientes pasos:

1. Primero, tienes que tener un disco que son las **Guest Additions**, esto sirve para que la máquina virtual que tengas, tenga opción de poner la **pantalla completa** y de poner las **carpetas compartidas** de tu ordenador principal.
2. Segundo, cuando se haya instalado las Guest Additions en tu Windows 8.1, vas al Internet Explorer (que es el explorador que viene de serie), busca **Descargar Google Chrome** para que busques mejor y para modificar o añadir cosas dentro del sistema.
3. Tercero, si ya tienes **Google Chrome** instalado, ahora tienes que buscar lo siguiente para añadir el clásico botón de inicio de Windows en Windows 8.1:
   
    *  Busca en Google, **Classic Shell for Windows 8.1 Start Menu**, para añadir el clásico botón de inicio por si no te gusta el menú de inicio del propio Windows 8.1.
    *  Luego te diriges a la página web.
